# 🛡️ Project Belisarius

**"Transform Data into Knowledge, Knowledge into Strategy."**

Belisarius, named after Flavius Belisarius—one of the greatest strategists in history and the renowned Eastern Roman general—is a high-performance strategic analysis and document processing assistant. Developed as an integral module of the **SyntaX** project, this system analyzes complex datasets to deliver critical decision-support reports to the user.

## 🧠 Hybrid Intelligence Architecture

Belisarius builds its power upon two massive pillars:
* **Ollama (Llama 3):** An offline strategic engine engineered to prioritize strict data privacy. *Note: In the latest architecture pivot, it has been decided to deploy Llama 3 via Groq instead of running it locally.*
* **Gemini 3 Flash:** A cloud-based backend delivering ultra-fast execution speeds alongside a massive context window for advanced analysis.

## ⚔️ Core Capabilities

* **Strategic Analysis:** Evaluates provided documents through tactical, socio-political, military, or technical lenses.
* **Document Intelligence (PDF Scanning):** Processes massive data volumes and PDF files within seconds to extract high-fidelity summaries and actionable insights.
* **Hybrid Decision Mechanism:** Merges on-premises security paradigms with the raw processing speed of the cloud to generate optimal responses under any scenario.

## 🕵️ Vision

Belisarius is not merely an AI assistant; it is a digital Chief of Staff. Its ultimate objective is to cut through the information warfare and noise of a complex world, provisioning the user with nothing but the purest and most strategic outcomes.
